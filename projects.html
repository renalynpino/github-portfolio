Data Analytics Project 01

Superstore Sales Analysis and Dashboard

One dataset, four tools, and a complete workflow from data cleaning to interactive visualization.

Project Overview:Analyzed Superstore sales data to explore sales performance across product categories, sub-categories, states, regions, and shipping modes. This project demonstrates an end-to-end data analysis workflow using four tools.

Tools and Workflow:

  1. Microsoft Excel — Data Cleaning: Cleaned and organized the dataset by checking missing values, duplicates, date formats, column names, and data consistency.
  2. PostgreSQL — SQL Analysis: Imported the cleaned dataset and used SQL queries to filter, aggregate, and examine sales data.
  3. Tableau — Data Visualization: Created a dashboard featuring sales KPIs, category and sub-category comparisons, top states by sales, shipping modes, a regional sales map, and interactive filters.
  4. Power BI — Dashboard Development: Recreated the Tableau dashboard using the same dataset, metrics, visualizations, and filters to demonstrate dashboard development in both tools.
