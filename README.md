## Featured Project

### Superstore Sales Performance Dashboard

This project analyzes Superstore sales data across product categories, sub-categories, states, regions, and shipping modes using one dataset and four tools:

1. **Microsoft Excel:** Cleaned and organized the dataset by checking missing values, duplicates, date formats, column names, and data consistency.
2. **PostgreSQL:** Imported the cleaned dataset and used SQL queries to filter, aggregate, and examine sales data.
3. **Tableau:** Created an interactive dashboard with sales KPIs, category and sub-category comparisons, top states by sales, shipping modes, a regional map, and filters. The dashboard is published on [Tableau Public](https://public.tableau.com/views/SuperstoreSalesPerformanceDashboard_17929044801770/SuperstoreSalesPerformanceDashboard?:showVizHome=no).
4. **Power BI:** Recreated the Tableau dashboard using the same dataset, metrics, visualizations, and filters. A static preview and the `.pbix` report are included in the portfolio.

The project demonstrates an end-to-end workflow from data cleaning and SQL analysis to dashboard development and presentation of insights.

## How to View Locally

This is a static website. With Node.js installed, open the project folder in the VS Code terminal and run:

```powershell
npx --yes serve . --listen 8000
```

Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in a browser. Press `Ctrl + C` in the terminal to stop the server.
